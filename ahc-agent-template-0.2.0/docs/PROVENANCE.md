# 出典と派生関係

AHC Agent Harness Template 0.1.0（2026-10-23）は、ユーザーへ提供済みの`codingame_agent_harness_template_v0.2.0.zip`を土台に構成した。
研究state、mission/予約、worktree、凍結artifact、sealed evidence、Beads、GitHub共有、保守的C++結合の設計と実装を引き継いだ。
AHC専用にケース管理、採点契約、対話テスタ接続、出力再採点、統計、可視化、提出準備、文書、回帰試験を追加/置換した。

元のCodinGame配布はLoCMリポジトリの`5f8fe5e01f4fee3d34719261cca86cc0a2614c5e`までの設計知見を再構成したもので、LoCMコア0.5.0のそのままのコピーではない。
今回も既存LoCM/既存AHCへ上書きするアップデータではなく、新規プロジェクト用。

共通コードは今後両配布へ還元できるが、このZIPだけで自動同期・双方向更新は提供しない。
AHCの過去/現在の利用規則、問題文、公式ジャッジ、外部ソルバー、学習済みデータは同梱しない。
模擬選択問題と隠れた整数探索のfixtureは、この配布の実行契約を検証するための小さな独自例。
Beads実行体も同梱しない。インストーラは元プロジェクトの公式releaseとchecksumを参照する。

## v0.2.0の更新（2026-10-30）

この配布物は0.1.0をコピーして、LoCMリポジトリの2026-10-29コミット `1183716b6f70fd0f6d52a25b49aa35c2551776f1` までに確認できた実践知見を参照し更新した独立派生版。LoCMの新しい大規模学習コードや対戦評価器はコピーしていない。

追加したのは入力byteを用いた露出ゲート、blockベースの精度目安、独立した実験結果軸、deadlineに応じた既定方策、AB-MCTSを含む任意の候補選択器。AHC公式ツールの実問題による検証ではない。

**注意**：このテンプレートとLoCMの本番コードを同一バージョン・同一実装だと表現しない。LoCMの研究データ、学習済みモデル、認証情報は付属しない。
