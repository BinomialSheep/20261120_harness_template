# 予算・権限と大会規則は別

AHCのAI利用条件は、ユーザーが案件ごとに必要な資料を渡す。ハーネスに特定大会・部門・期間の制約はない。
missionが管理するのは、主に「このPCで何をどれくらい実行してよいか」。

100入力×候補/基準×3乱数なら600 solver_runs。生成した入力数はgenerated_cases、再採点はjudge_runs。
一試行のwall time上限はcontract、実験全体の実行時間上限はsuite、研究合計の試行数はmissionにある。
失敗した試行も予算を消費し、途中終了で消費を消さない。

CPU/GPU秒やLLM tokenはすべてを自動計測していない。測れていない単位を0と表示しない。
見積りだけの資源は最後に実測/不明を明示して精算し、未計測を理由に無制限へ広げない。

人間の着想は既存予算内での投資判断の材料。予算を増やす、課金する、公開する、提出する権限そのものではない。
GitHub Issues書込みも、ローカルBeads更新やGit commitとは別の外部操作。

停止は以後の公認操作を止める。起動済みのジョブを自動killする仕組みはこの版にはなく、状態を確認して安全に止める。
