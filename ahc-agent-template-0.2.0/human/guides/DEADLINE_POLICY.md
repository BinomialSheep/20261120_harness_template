# 時間がないコンテストでどう判断するか

本番開始後に「Greedy、AB-MCTS、遺伝的探索のどれが勝つか」をすべて比較する余裕はない。初回は、実験の結果と残り時間で**次の研究行動**を選ぶ既定方策を用いる。

[次行動の状態例](../../research/next_action.example.json) をコピーし、**その大会の締切と、提出前確認に必要な余裕**を設定する。実際の締切は人間から渡された情報を使い、ハーネス側で推測しない。

```sh
python3 -m harness next-action --state research/next_action.json
```

初期解がないならまず合法解、測定の不整合があれば診断、測定可能で改善が続くなら改善、停滞すれば別系統。残り時間が確認用に確保した時間以下になったら、未確定の新規解法へ突っ込まず、いまある成果を検証・保存する。

これは**一つの説明可能な初期方策**で、最適性を保証する学習済みモデルではない。採用ルール・予算・権限は別のmissionで確定する。
