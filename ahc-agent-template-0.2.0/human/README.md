# 人間向けの入口

普段の会話はVS CodeのClaude Code/Codexへ。研究の現状は[STATUS](../docs/STATUS.md)、背景を知りたいときはここを読む。
エージェントの全チャットを追わなくてよい構成を目指しています。

| やりたいこと | 資料 |
|---|---|
| 解凍した後、まず何をする？ | [最初の手順](guides/START_HERE.md) |
| 何が入っていて、どうつながる？ | [全体像](guides/HARNESS_OVERVIEW.md) |
| この問題で実際に何を実行する？ | [問題ごとの接続メモ](guides/PROBLEM_ONBOARDING.md) |
| 比較スコアは何を意味する？ | [AHC評価](guides/AHC_EVALUATION.md) |
| 入力を生成・分割するには？ | [ケース管理](guides/CASE_MANAGEMENT.md) |
| 研究を任せる・口を出す | [研究フロー](guides/RESEARCH_WORKFLOW.md) |
| 焼きなまし・パラメータの実験 | [最適化の進め方](guides/OPTIMIZATION_WORKFLOW.md) |
| 長い処理と短い改善を並行したい | [並列セッション](guides/PARALLEL_SESSIONS.md) |
| 予算と承認の意味を知る | [予算・権限](guides/BUDGET_AND_PERMISSIONS.md) |
| データを失いたくない | [バックアップ](guides/BACKUP_AND_RECOVERY.md) |
| 動かない・結果がおかしい | [トラブルシュート](guides/TROUBLESHOOTING.md) |
| 回答を保存する | [Q&A](questions/README.md) |
| 個人的なメモを置く | [メモ](notes/README.md) |

`human/local/`と通常の`human/notes/`内ファイルはGit管理外。Web版ChatGPTに読ませたいものだけ、明示的に共有する。
ここに思いつきを書いただけで研究方針が変わったり、Beadsへ自動登録されたりはしない。
