## 使い方

各テンプレート内に使用方法が書いてありますが、人間が読んでその通りにやることは想定していません。
プロジェクトのフォルダに問題文、公式ツール、テンプレートを置いて、「テンプレートに従って環境構築してください」と依頼しています。

問題文は、pdfやSingleFileなどでダウンロードしたものを、ChatGPTに依頼して余計なリンクや文章を削除したmdもしくはhtmlに変換させてます。
公式ツールとしては、AHCならRustのジャッジ、コドゲなら公式リポジトリを丸ごとダウンロードしています。
