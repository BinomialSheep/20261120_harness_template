## V1：テスト（LLM なし）

`python3 -m unittest discover -s tests` の全件が通る（約30秒）。中身：

- 案の検査、課題の雛形、関数一覧。
- 模擬問題で A を一周：段階式の足切り、無効の候補、昇格、notes.md の写し、研究の記録の1行、レポート。
- B（親2本・参考ファイル、段階なし・確認なし）、C（report.md と out/ の写し、評価なしで close）、`go --background`。
- 確認評価で採否が決まること、続きから・`--restart`。
- 利用上限で止まった worker が interrupted になり、accept で提出できること。作業場所に切り離して残したプロセスが止まること。
- 判定が JSON を書かずに失敗すると、候補を無効にせず評価が止まること。
- 終わり方の判定（通信断・利用上限・上限の話をしただけ）、待つだけの呼び出しの数え方。
- 汎用アダプタ：得点、特徴量、WA、TLE、RE、`--time-scale`、ツールが無いときの環境エラー。
- 配備：既存ファイルを上書きしない、.gitignore に config.json を入れない。
